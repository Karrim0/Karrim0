I'm a Frontend Engineer specialized in **React.js**, **Next.js**, **TypeScript**, and modern web interfaces.

I build responsive, scalable, and user-focused web applications with strong attention to clean UI, API integration, multilingual experiences, admin dashboards, and real-world product flows.

Full-stack multilingual e-commerce platform for kids products, built with Next.js, TypeScript, Prisma, Neon/PostgreSQL, and Tailwind CSS.

The platform includes a responsive storefront, real checkout flow, website and WhatsApp ordering, local payment options, shipping settings, and a complete admin dashboard for managing products, categories, brands, orders, discounts, media, homepage content, and store settings.

**Tech:** Next.js, TypeScript, Prisma, Neon, PostgreSQL, Tailwind CSS, next-intl, Admin Dashboard
